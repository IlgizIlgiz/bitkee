# bitkee-fast — быстрый CLI-солвер пазлов

Нативный многопоточный перебор ключей с **batch-inversion** (инкрементальное
сложение точек вместо умножения `k·G` на каждый ключ).
**~6.5M ключей/сек** на Mac M4 (10 ядер) — примерно в 34 раза быстрее старого `cli/`.

---

## Как запустить (короткая версия)

```bash
./cli-fast/target/release/bitkee-fast
```

Откроется меню: выбери **пазл → режим → потоки → интенсивность** стрелками, Enter — поехали.
Остановить — **Ctrl+C**.

> Запускать можно из любой папки проекта. Бинарь уже собран и лежит в `target/release/`.

---

## Первый раз / после правки кода

Если бинаря ещё нет или менял код — сначала собрать (нужен Rust):

```bash
cd cli-fast
cargo build --release
```

Готовый бинарь появится в `cli-fast/target/release/bitkee-fast`.

Если Rust не установлен:
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"
```

---

## Запуск с аргументами (без меню)

```bash
./cli-fast/target/release/bitkee-fast -p 71 -t 10 -m random -i turbo
```

| Флаг | Значение | Варианты |
|------|----------|----------|
| `-p <id>` | какой пазл | см. список ниже |
| `-t <N>`  | сколько потоков | 1…число ядер (на M4 = 10) |
| `-m <режим>` | как искать | `sequential` \| `random` |
| `-i <инт.>`  | нагрузка CPU | `eco` \| `normal` \| `turbo` |

Через `cargo run` (сам пересоберёт если менял код) — аргументы после `--`:
```bash
cd cli-fast
cargo run --release -- -p 71 -t 10 -m random -i turbo
```

---

## Режимы поиска (`-m`)

- **sequential** — делит диапазон на потоки, каждый идёт по своему куску по порядку.
  Гарантированно находит, если ключ в диапазоне. **Лучший для мелких/тестовых пазлов.**
- **random** — каждый поток прыгает по случайным стартам и идёт сегментами.
  Для огромных пазлов (#66+), где полный перебор невозможен.

## Интенсивность (`-i`) — нагрузка на процессор

| Режим | Паузы | CPU | Скорость (пример, 4 ядра) |
|-------|-------|-----|----------|
| `eco`    | 50 мс между батчами | холодный | ~150K/s |
| `normal` | 10 мс | умеренный | ~средне |
| `turbo`  | без пауз | максимум 🔥 | ~8.5M/s |

`eco` — если ноут греется / хочешь фоном. `turbo` — выжать максимум.

---

## Доступные пазлы (`-p`)

| id | что | бит | находится перебором? |
|----|-----|-----|----------------------|
| 0  | 🧪 Test Puzzle | 17 | да, мгновенно (демо) |
| 10,13,15,16 | мелкие решённые | 10–16 | да, за секунды |
| 66–70,75 | большие решённые | 66–75 | нет (только смотреть процесс) |
| 71,72,73,74 | **нерешённые, ~7 BTC** | 71–74 | теоретически — на практике лотерея |

Полный список с адресами: `./cli-fast/target/release/bitkee-fast --help`

---

## Где результат

При находке ключ печатается на экран **и** сохраняется в файл
`puzzle_<id>_found.txt` (HEX + WIF + адрес).

---

## Трезвая правда про большие пазлы

На #71 даже 6.5M/s против пространства 2⁷⁰ ≈ 10²¹ ключей — это лотерея на сотни тысяч
лет. Скорость реальная, но чудес с большими пазлами не будет. Мелкие и тестовый —
находятся мгновенно (для проверки, что всё работает).
